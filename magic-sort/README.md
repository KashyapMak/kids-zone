# 🧪 Magic Sort – Water Sort Puzzle

A fun and colorful puzzle game built for Kids Zone. Sort liquids across glass test tubes until each tube contains only one color.

---

## 🎯 Objective

Arrange all colored liquids so:
- Each tube has a **single color only**, or
- The tube is completely **empty**

---

## 🎮 How to Play

- Tap a tube to pick it
- Tap another tube to pour

### Rules
- Each tube can hold **4 layers**
- You can pour if:
  - Target tube is empty OR
  - Target has the **same top color**
- Only matching top layers will be poured together

---

## 🎮 Game Modes

### 🧘 Practice Mode
- No time limit
- Play at your own pace

### ⏰ Timed Mode
- Complete the level before time runs out
- Visual timer bar shows remaining time

---

## 🎚 Difficulty Levels

Choose at the start:

- 😊 Easy – More empty tubes
- 🧐 Medium – Balanced gameplay
- 🔥 Hard – Fewer empty tubes

---

## 🧩 Screens

### ✅ Home Screen
- Select difficulty
- Select mode
- Start / Continue / Reset

⚠️ Continue & Reset only appear when progress exists

---

### 🎮 Game Screen
- Level indicator
- Timer (timed mode)
- Tube grid
- Controls:
  - ↩ Undo
  - 🔄 Restart (same puzzle)
  - 🏁 Home

---

### 🏆 Result Screen

#### On Success
- ➡ Next Level
- 🏠 Home

#### On Time Up
- 🔁 Retry (new puzzle)
- 🔄 Restart (same puzzle)
- 🏠 Home

---

## 💾 Progress Saving

The game automatically saves:

You can:
- Continue from last progress
- Reset anytime from home screen
