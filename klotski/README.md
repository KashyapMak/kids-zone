# 🧩 KLOTSKI Trail

**KLOTSKI Trail** is a single‑file, kid‑friendly **sliding tile puzzle** inspired by the classic wooden Klotski board game.  
Learners slide numbered tiles into ascending order by moving them into the one empty space — one tile at a time.

It follows the same feel as the *Trail* series (Times Table Trail, Add & Sub Trail, Deci‑Frac Trail): kid‑safe design, themed UI, audio feedback, best‑score tracking, and a responsive layout that works on any device. Works **offline** and needs **no build tools**.

---

## ✨ Highlights

* **Three difficulty modes:**
  - 🟩 **Simple** — 4×4 grid (15 tiles)
  - 🟦 **Medium** — 8×8 grid (63 tiles)
  - 🟥 **Hard** — 12×12 grid (143 tiles)
* **Sliding puzzle mechanics** — click or tap any tile adjacent to the empty space to slide it
* **Keyboard control** — Arrow keys slide tiles; `H` highlights moveable tiles; `R` resets; `N` new shuffle
* **Space Mono numerals** on tiles for a clean, monospaced engraved look
* **Board frame** tints to match the active theme colour
* **Move counter + live timer** — start on first move, stop on solve
* **Best score** saved per mode in `localStorage` (fewest moves + time)
* **Hint** — flashes all currently moveable tiles in gold so learners can see their options
* **Reset** — returns the board to the start of the current shuffle without generating a new one
* **Guaranteed solvable puzzles** — all shuffles are generated by walking valid moves from the solved state
* **Win detection** with confetti 🎉 and a result overlay showing moves and time
* **Kid‑friendly UI:** Jungle theme (default), six themes, high‑contrast mode, big tiles, fun fonts
* **Audio:** feedback sounds on slide and win (on by default, toggleable)
* **Offline:** single HTML file, no build step, no tracking

## 🚀 Getting Started

1. Open the folder `klotski/`.
2. Double‑click **`klotski-trail.html`** to open it in your browser.
3. Pick a difficulty mode → tiles are shuffled automatically → start sliding!

> Works offline in modern browsers (Chrome, Edge, Firefox, Safari).

---

## 🧩 How to Play

1. Pick a **difficulty**: Simple (4×4), Medium (8×8), or Hard (12×12).
2. The board shuffles automatically — tiles are always solvable.
3. **Slide tiles** into the empty space by clicking/tapping them, or use the Arrow Keys.
4. Arrange all tiles **1 → N** in reading order, with the **empty space at the bottom‑right**.
5. The timer starts on your **first move** and stops when the puzzle is solved.
6. View your **move count**, **time**, and whether you beat your **best score**.
7. Press 🔀 **New Shuffle** for a fresh puzzle, or **↺ Reset** to go back to the start of the current one.

## 🎮 Keyboard Shortcuts

| Key | Action |
|---|---|
| `Arrow Keys` | Slide the tile in the direction of the empty space |
| `H` | Hint — highlight all moveable tiles in gold |
| `R` | Reset to start of current shuffle |
| `N` | New shuffle |
| `🔊` | Toggle sound on/off |
| `🌓` | Toggle high‑contrast mode |
| `❓` | Open help / shortcuts dialog |

> Arrow key direction: press the arrow that **points toward the empty space**. For example, if the empty space is to the right, press `→`.

---

## ⏱️ Timing & Scoring

* The timer starts on your **first move** and stops the moment the puzzle is solved.
* The **move counter** increments on every tile slide.
* **Best score** (fewest moves + fastest time) is stored in `localStorage` per difficulty mode and shown in the header stats bar.
* Best score updates automatically if you beat your previous record.

---

## 💡 Hint System

Press the **💡 Hint** button (or press `H`) to briefly highlight all tiles that are currently slideable — they glow gold for one second. This helps younger learners identify which tiles they can move without giving away the solution.

---

## 🔀 Puzzle Generation

All puzzles are generated by starting from the **solved state** and making a series of random valid moves (80 for Simple, 200 for Medium, 350 for Hard). This guarantees every puzzle is solvable and avoids the unsolvable configurations that can occur with purely random shuffles.

```js
const MODES = {
  simple: { n: 4,  label: 'Simple (4×4)',  shuffles: 80  },

  hard:   { n: 12, label: 'Hard (12×12)', shuffles: 350 }

let mode    = 'simple';   // current difficulty
let isMuted = false;      // sound toggle
```

## 🐛 Troubleshooting

* **Tiles won't slide?** Only tiles directly adjacent (up/down/left/right) to the empty space can move — diagonal moves are not allowed.
* **Arrow keys not working?** Click anywhere on the board first to give it keyboard focus.
* **No sound?** Make sure the 🔊 toggle is on. Some browsers require a user gesture before audio plays.
* **Fonts look different offline?** Web fonts load from Google Fonts; offline it falls back to system fonts.
